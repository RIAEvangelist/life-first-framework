# Changelog

All notable public changes are recorded here. Dates use ISO 8601.

## [0.2.0] — 2026-08-07

### Added

- Normative commitments, operating cycle, risk tiers, required records, pause conditions, and scoped conformance rules.
- Charter, governance model, decision protocol, implementation guide, pilot plan, metrics guide, threat model, glossary, and FAQ.
- Reusable templates for intake, impact mapping, evidence, decisions, pilots, metrics, incidents, appeals, changes, and provenance.
- Machine-readable decision-record schema and a fully fictional worked example.
- Expanded accessible public site and documentation navigation.

### Changed

- Reframed the repository from a minimal scaffold to a usable public working draft.
- Strengthened contribution and provenance requirements.

### Safeguard impact

- Added mandatory pause conditions, risk-based review, appeals, rollback, incident readiness, anti-retaliation, and limits on conformance claims.
- No existing safeguard was removed or weakened.

## [0.1.0] — 2026-08-05

- Published the original clean public scaffold, core principles, contribution guidance, provenance record, and GitHub Pages site.
