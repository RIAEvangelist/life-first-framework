Records that make practice reviewable

The toolkit.

Choose records by the decision stage. The website explains when each record is needed; the repository retains the copyable source templates.

How to use the toolkit

Begin with the workflow, then add records in proportion to consequence.

Need the process before the paperwork? Follow the Implementation guide.

1

Start with System Intake.

Define the purpose, boundary, people, data, roles, initial risk, and whether the work should proceed.

2

Add records by stage and consequence.

Use the directory below to select evidence, authorization, pilot, repair, change, and transparency records as needed.

3

Keep the working copies controlled.

Store project records in a versioned, access-controlled evidence repository. Never put personal, confidential, classified, or exploit-enabling detail in a public repository.
