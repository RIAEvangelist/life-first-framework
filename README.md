# Life First Framework

An open, clean-room scaffold for practical AI work that puts human life, dignity, agency, and accountability first.

## Current status

This repository contains only original, non-sensitive material prepared for public release. It does not reproduce private correspondence, attachments, confidential material, or third-party contributions that have not been explicitly cleared for publication.

## Working principles

- Protect life and reduce foreseeable harm.
- Preserve human agency and meaningful oversight.
- Make system limits, assumptions, and uncertainty legible.
- Keep decisions auditable and attributable.
- Prefer reversible, proportional actions when consequences are uncertain.
