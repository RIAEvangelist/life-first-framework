# Life First Framework

An open framework for practical AI work that puts human life, dignity, agency, and accountability first.

## Current status

Version 0.1 is live as an original, non-sensitive public scaffold. It does not reproduce private correspondence, attachments, confidential material, or third-party contributions that have not been explicitly cleared for publication.

Read the [framework](FRAMEWORK.md) and the [provenance and attribution record](PROVENANCE.md).

## Working principles

- Protect life and reduce foreseeable harm.
- Preserve human agency and meaningful oversight.
- Make system limits, assumptions, and uncertainty legible.
- Keep decisions auditable and attributable.
- Prefer reversible, proportional actions when consequences are uncertain.
